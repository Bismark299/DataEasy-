DataEasy+ API

Integrate data bundle purchases into your website or app. Orders are charged against your DataEasy+ wallet balance and delivered automatically.

How it works

1

Create an API Key

Generate a key from your API Keys page.

2

Fund Your Wallet

Top up your wallet. Orders debit this balance.

3

Make API Calls

List packages, place orders from your backend.

4

Auto Delivery

Bundles are delivered automatically to the phone number.

Authentication

All requests must include your API key in the X-API-Key header.

GET /api/v1/packages HTTP/1.1
Host: your-domain.com
X-API-Key: de_live_abcdef1234567890...

Security Best Practices

  • Never expose your API key in client-side JavaScript
  • Make API calls from your server (backend) only
  • Use domain whitelisting for extra security
  • Rotate keys regularly

Permissions

POST /api/v1/orders

Place a new data bundle order. Debits your wallet and auto-delivers.

Request Body

{
  "network": "MTN",
  "items": [
    {
      "packageId": "mtn-5gb",
      "phoneNumber": "0241234567"
    }
  ]
}

Parameters

FieldTypeRequiredDescription
networkstringRequiredMTN, AirtelTigo, or Telecel
itemsarrayRequiredUp to 10 items per order
items[].packageIdstringRequiredPackage ID from /packages
items[].phoneNumberstringRequiredGhana number (e.g. 0241234567)

Error Codes

All errors return { "success": false, "error": "..." }

StatusMeaning
400Bad request — invalid parameters or insufficient wallet balance
401Unauthorized — missing or invalid API key
403Forbidden — insufficient permissions or blocked domain
404Not found — resource doesn't exist
429Rate limited — too many requests (60/min default)
500Server error — contact support
503Service unavailable — try again later
 
// Example error response
{
  "success": false,
  "error": "Insufficient wallet balance.",
  "required": 18.00,
  "available": 5.00
}

Rate Limits

Default: 60 requests per minute per API key. Rate limit info is included in response headers.

HeaderDescription
RateLimit-LimitMaximum requests per window
RateLimit-RemainingRequests remaining in current window
RateLimit-ResetSeconds until the window resets

Code Examples

const API_KEY = 'de_live_your_key_here';
const BASE_URL = 'https://your-domain.com/api/v1';

// List packages
async function getPackages() {
  const res = await fetch(`${BASE_URL}/packages`, {
    headers: { 'X-API-Key': API_KEY }
  });
  return res.json();
}

// Place an order
async function placeOrder(network, packageId, phoneNumber) {
  const res = await fetch(`${BASE_URL}/orders`, {
    method: 'POST',
    headers: {
      'X-API-Key': API_KEY,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      network,
      items: [{ packageId, phoneNumber }]
    })
  });
  return res.json();
}

// Check balance
async function checkBalance() {
  const res = await fetch(`${BASE_URL}/balance`, {
    headers: { 'X-API-Key': API_KEY }
  });
  return res.json();
}

// Usage
const packages = await getPackages();
const order = await placeOrder('MTN', 'mtn-5gb', '0241234567');
console.log('Order placed:', order.order.orderId);
import requests

API_KEY = "de_live_your_key_here"
BASE_URL = "https://your-domain.com/api/v1"
HEADERS = {"X-API-Key": API_KEY, "Content-Type": "application/json"}

# List packages
packages = requests.get(f"{BASE_URL}/packages", headers=HEADERS).json()

# Place an order
order = requests.post(f"{BASE_URL}/orders", headers=HEADERS, json={
    "network": "MTN",
    "items": [{"packageId": "mtn-5gb", "phoneNumber": "0241234567"}]
}).json()

print(f"Order #{order['order']['orderId']} placed!")

# Check balance
balance = requests.get(f"{BASE_URL}/balance", headers=HEADERS).json()
print(f"Balance: GHS {balance['balance']}")
<?php
$apiKey = "de_live_your_key_here";
$baseUrl = "https://your-domain.com/api/v1";

function apiRequest($method, $endpoint, $body = null) {
    global $apiKey, $baseUrl;
    $ch = curl_init("$baseUrl$endpoint");
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_HTTPHEADER, [
        "X-API-Key: $apiKey",
        "Content-Type: application/json"
    ]);
    if ($method === "POST") {
        curl_setopt($ch, CURLOPT_POST, true);
        curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($body));
    }
    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
}

// List packages
$packages = apiRequest("GET", "/packages");

// Place an order
$order = apiRequest("POST", "/orders", [
    "network" => "MTN",
    "items" => [["packageId" => "mtn-5gb", "phoneNumber" => "0241234567"]]
]);

echo "Order #{$order['order']['orderId']} placed!\n";

// Check balance
$balance = apiRequest("GET", "/balance");
echo "Balance: GHS {$balance['balance']}\n";
?>
