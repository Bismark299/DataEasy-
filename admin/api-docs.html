Getting Started

The DataEasy+ API allows you to integrate data bundle purchases into your own website or application. Orders are charged against your DataEasy+ wallet balance.

Loading...

How it works

  1. Create an API key from your dashboard (Account > API Keys)
  2. Fund your DataEasy+ wallet
  3. Make API calls with your key to list packages and place orders
  4. Orders debit your wallet and are automatically delivered

Authentication

All API requests require an X-API-Key header with your secret API key.

GET /api/v1/packages
Host: your-domain.com
X-API-Key: de_live_abcdef1234567890...

Security Tips:

  • Never expose your API key in client-side JavaScript
  • Make API calls from your server (backend) only
  • Use IP whitelisting for extra security
  • Rotate keys regularly

Orders

POST /api/v1/orders

Place a new data bundle order. Debits your wallet and auto-delivers the bundle.

Request Body

{
  "network": "MTN",
  "items": [
    {
      "packageId": "mtn-5gb",
      "phoneNumber": "0241234567"
    }
  ]
}

Parameters

FieldTypeDescription
networkstringRequired. MTN, AirtelTigo, or Telecel
itemsarrayRequired. Up to 10 items per order
items[].packageIdstringRequired. Package ID from /packages
items[].phoneNumberstringRequired. Ghana number (e.g. 0241234567)

Error Handling

All errors return a JSON object with success: false and an error message.

StatusMeaning
400Bad request — invalid parameters or insufficient balance
401Unauthorized — missing or invalid API key
403Forbidden — insufficient permissions or blocked IP/domain
404Not found — resource doesn't exist
429Rate limited — too many requests (default: 60/min)
500Server error
503Service unavailable — try again later
 
// Error response example
{
  "success": false,
  "error": "Insufficient wallet balance.",
  "required": 18.00,
  "available": 5.00
}

Code Examples

JavaScript (Node.js / Fetch)

const API_KEY = 'de_live_your_key_here';
const BASE_URL = 'https://your-domain.com/api/v1';

// List packages
async function getPackages() {
  const res = await fetch(`${BASE_URL}/packages`, {
    headers: { 'X-API-Key': API_KEY }
  });
  return res.json();
}

// Place an order
async function placeOrder(network, packageId, phoneNumber) {
  const res = await fetch(`${BASE_URL}/orders`, {
    method: 'POST',
    headers: {
      'X-API-Key': API_KEY,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      network,
      items: [{ packageId, phoneNumber }]
    })
  });
  return res.json();
}

// Check balance
async function checkBalance() {
  const res = await fetch(`${BASE_URL}/balance`, {
    headers: { 'X-API-Key': API_KEY }
  });
  return res.json();
}

// Usage
const packages = await getPackages();
console.log(packages.packages.MTN);

const order = await placeOrder('MTN', 'mtn-5gb', '0241234567');
console.log('Order placed:', order.order.orderId);

Python (requests)

import requests

API_KEY = "de_live_your_key_here"
BASE_URL = "https://your-domain.com/api/v1"
HEADERS = {"X-API-Key": API_KEY, "Content-Type": "application/json"}

# List packages
packages = requests.get(f"{BASE_URL}/packages", headers=HEADERS).json()

# Place an order
order = requests.post(f"{BASE_URL}/orders", headers=HEADERS, json={
    "network": "MTN",
    "items": [{"packageId": "mtn-5gb", "phoneNumber": "0241234567"}]
}).json()

print(f"Order #{order['order']['orderId']} placed!")

# Check balance
balance = requests.get(f"{BASE_URL}/balance", headers=HEADERS).json()
print(f"Balance: GHS {balance['balance']}")

PHP (cURL)

<?php
$apiKey = "de_live_your_key_here";
$baseUrl = "https://your-domain.com/api/v1";

function apiRequest($method, $endpoint, $body = null) {
    global $apiKey, $baseUrl;
    $ch = curl_init("$baseUrl$endpoint");
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_HTTPHEADER, [
        "X-API-Key: $apiKey",
        "Content-Type: application/json"
    ]);
    if ($method === "POST") {
        curl_setopt($ch, CURLOPT_POST, true);
        curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($body));
    }
    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
}

// List packages
$packages = apiRequest("GET", "/packages");

// Place an order
$order = apiRequest("POST", "/orders", [
    "network" => "MTN",
    "items" => [["packageId" => "mtn-5gb", "phoneNumber" => "0241234567"]]
]);

echo "Order #{$order['order']['orderId']} placed!\n";

// Check balance
$balance = apiRequest("GET", "/balance");
echo "Balance: GHS {$balance['balance']}\n";
?>

Rate Limits

Default rate limit is 60 requests per minute per API key. Rate limit headers are included in responses:

HeaderDescription
RateLimit-LimitMaximum requests per window
RateLimit-RemainingRequests remaining in current window
RateLimit-ResetSeconds until window resets
