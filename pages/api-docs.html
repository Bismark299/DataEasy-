DataEasy+ API

v1

Integrate Ghana data bundle purchases directly into your website or application. Orders are charged against your DataEasy+ wallet balance and delivered automatically to the recipient's phone number.

How it works

1

Create an API Key

Generate a key from your API Keys page and assign the scopes you need.

2

Fund Your Wallet

Top up your DataEasy+ wallet. Every order is debited from this balance.

3

Make API Calls

List packages and place orders from your server-side code only — never expose your key client-side.

4

Automatic Delivery

Bundles are dispatched automatically to the phone number provided in the order.

Authentication

All requests must include your API key in the X-API-Key request header.

HTTP 
GET /api/v1/packages HTTP/1.1
Host: your-domain.com
X-API-Key: de_live_abcdef1234567890...

Security Best Practices

  • Never expose your API key in client-side JavaScript or mobile apps
  • Make all API calls from your server (backend) only
  • Use domain whitelisting on your key for extra protection
  • Rotate keys immediately if you suspect they have been compromised

Permissions

Each API key carries specific permission scopes. Only grant the scopes your integration actually needs.

ScopeDefaultDescription
packages:read Always included List available packages and role-based prices
orders:create Optional Place new data bundle orders and debit wallet
orders:read Optional View order history and per-item delivery status
account:read Optional Read wallet balance and account details

Idempotency

Add an X-Idempotency-Key header to POST /orders to make it safe to retry. If your server retries a request that already succeeded, the API returns the original response instead of creating a duplicate order and charging you again.

HTTP 
POST /api/v1/orders HTTP/1.1
X-API-Key: de_live_your_key_here
X-Idempotency-Key: my-order-uuid-or-any-unique-string
Content-Type: application/json
DetailValue
HeaderX-Idempotency-Key
RequiredOptional — omit to disable idempotency
FormatAny string 16–255 characters (UUID recommended)
ScopePer API key + per endpoint — the same key can be reused on different endpoints
TTLKeys expire after 24 hours

How it works

First call

Order is created, wallet debited, delivery started. Response is cached against your key.

Retry with same key

The cached response is returned instantly. No new order, no new charge. Response includes "_idempotent": true.

New key

A genuinely new order is created. Use a fresh key for each intended transaction.

Best practice

Generate a UUID per order attempt on your side (e.g. crypto.randomUUID()) and store it with the pending order in your database before calling this API. On any retry, reuse the same UUID. This guarantees exactly-once delivery even under network failures.

Webhooks

Pass an optional callbackUrl in your POST /orders body. When each item is delivered or fails, we POST a delivery event to that URL — no polling required.

Webhook payload

{
  "event": "order.item.delivered",
  "orderId": "0042",
  "orderUuid": "9f2e1d3a-...",
  "itemIndex": 0,
  "item": {
    "phoneNumber": "0241234567",
    "data": "1GB",
    "packageId": "mtn-1gb",
    "deliveryStatus": "Delivered",
    "providerReference": "BT-42-0-1748993412345",
    "deliveredAt": "2026-06-03T10:05:32.000Z",
    "deliveryError": null
  },
  "orderStatus": "Delivered",
  "timestamp": "2026-06-03T10:05:32.123Z"
}
FieldDescription
eventorder.item.delivered or order.item.failed
orderIdYour human-readable order number
itemIndexZero-based index of the item in your original items array
orderStatusOverall order status after this item resolved — Delivered, Partially Delivered, or Failed

Delivery rules

  • One webhook per item — if an order has 3 items, you receive up to 3 separate events.
  • We retry up to 3 times with exponential back-off (1s then 2s) if your server does not return a 2xx response.
  • Each attempt times out after 10 seconds. Respond quickly — do your processing asynchronously.
  • callbackUrl must be HTTPS.
  • Requests include a X-DataEasy-Event header with the event name for quick routing.

Example — order with callback

cURL 
curl -X POST https://your-domain.com/api/v1/orders \
  -H "X-API-Key: de_live_your_key_here" \
  -H "X-Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "network": "MTN",
    "callbackUrl": "https://yoursite.com/webhooks/dataeasy",
    "items": [{ "packageId": "mtn-1gb", "phoneNumber": "0241234567" }]
  }'

Body Parameters

FieldTypeRequiredDescription

Error Codes

All error responses follow the same shape:

JSON 
{
  "success": false,
  "error": "Insufficient wallet balance.",
  "required": 18.00,
  "available": 5.00
}
StatusMeaning
400Bad request — invalid parameters or insufficient wallet balance
401Unauthorized — missing or invalid API key
403Forbidden — key lacks required scope, or domain is not whitelisted
404Not found — the requested resource does not exist
429Too many requests — rate limit exceeded, back off and retry
500Internal server error — contact support if persistent
503Service unavailable — delivery provider temporarily unreachable

Rate Limits

All API key requests share a default limit of 60 requests per minute per key. If you exceed this limit you will receive a 429 Too Many Requests response.

Retry Strategy

  • When you receive a 429, wait at least 1 second then retry with exponential back-off.
  • Batch multiple numbers into a single order request (up to 10 items) to minimise API calls.
  • Cache the GET /packages response — package lists change infrequently.

Code Examples

Node.js / Fetch 
const API_KEY  = 'de_live_your_key_here';
const BASE_URL = 'https://your-domain.com/api/v1';

async function apiRequest(method, path, body) {
  const res = await fetch(`${BASE_URL}${path}`, {
    method,
    headers: {
      'X-API-Key': API_KEY,
      'Content-Type': 'application/json'
    },
    body: body ? JSON.stringify(body) : undefined
  });
  const data = await res.json();
  if (!data.success) throw new Error(data.error);
  return data;
}

// List packages
const { packages } = await apiRequest('GET', '/packages');
console.log(packages.MTN);

// Place an order
const result = await apiRequest('POST', '/orders', {
  network: 'MTN',
  items: [{ packageId: 'mtn-5gb', phoneNumber: '0241234567' }]
});
console.log('Order #' + result.order.orderId, '— Balance:', result.walletBalance);

// Check balance
const { balance } = await apiRequest('GET', '/balance');
console.log(`GHS ${balance}`);
Python · requests 
import requests

API_KEY  = "de_live_your_key_here"
BASE_URL = "https://your-domain.com/api/v1"
HEADERS  = {"X-API-Key": API_KEY, "Content-Type": "application/json"}

def api(method, path, **kwargs):
    r = requests.request(method, BASE_URL + path, headers=HEADERS, **kwargs)
    data = r.json()
    if not data.get("success"):
        raise Exception(data.get("error"))
    return data

# List packages
pkgs = api("GET", "/packages")
print(pkgs["packages"]["MTN"])

# Place an order
order = api("POST", "/orders", json={
    "network": "MTN",
    "items": [{"packageId": "mtn-5gb", "phoneNumber": "0241234567"}]
})
print(f"Order #{order['order']['orderId']} — Balance: GHS {order['walletBalance']}")

# Check balance
bal = api("GET", "/balance")
print(f"GHS {bal['balance']}")
PHP · cURL 
<?php
define('API_KEY',  'de_live_your_key_here');
define('BASE_URL', 'https://your-domain.com/api/v1');

function apiRequest(string $method, string $path, ?array $body = null): array {
    $ch = curl_init(BASE_URL . $path);
    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_CUSTOMREQUEST  => $method,
        CURLOPT_HTTPHEADER     => [
            'X-API-Key: ' . API_KEY,
            'Content-Type: application/json'
        ],
        CURLOPT_POSTFIELDS => $body ? json_encode($body) : null
    ]);
    $response = json_decode(curl_exec($ch), true);
    curl_close($ch);
    if (!$response['success']) throw new Exception($response['error']);
    return $response;
}

// List packages
$pkgs = apiRequest('GET', '/packages');
print_r($pkgs['packages']['MTN']);

// Place an order
$result = apiRequest('POST', '/orders', [
    'network' => 'MTN',
    'items'   => [['packageId' => 'mtn-5gb', 'phoneNumber' => '0241234567']]
]);
echo "Order #{$result['order']['orderId']} — Balance: GHS {$result['walletBalance']}\n";

// Check balance
$bal = apiRequest('GET', '/balance');
echo "GHS {$bal['balance']}\n";
?>
