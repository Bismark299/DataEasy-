Quick Start

Once you have your API key, you can start making requests from your server:

// Fetch available data packages
const res = await fetch('/api/v1/packages', {
  headers: { 'X-API-Key': 'de_live_your_key_here' }
});
const data = await res.json();

// Place an order (debits your wallet)
const order = await fetch('/api/v1/orders', {
  method: 'POST',
  headers: {
    'X-API-Key': 'de_live_your_key_here',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    network: 'MTN',
    items: [{ packageId: 'mtn-5gb', phoneNumber: '0241234567' }]
  })
});
